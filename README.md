# Compliance Monitoring System 2026

An AI-powered Compliance Monitoring System designed to monitor transactions, analyze communications, identify potential compliance violations, maintain audit records, and generate compliance reports.

## Features

- Transaction monitoring
- Communication compliance checking
- Regulation management
- Risk and violation detection
- Audit log management
- Compliance report generation
- REST API
- Web-based dashboard
- SQLite database

## Technologies Used

- Python
- FastAPI
- SQLite
- HTML
- CSS
- JavaScript
- REST API
- AI-based monitoring agents

## Project Modules

1. Transaction Monitoring Agent
2. Communication Monitoring Agent
3. Regulation Agent
4. Audit Agent
5. Report Generation Agent

## Objective

The main objective of this project is to automate compliance monitoring and help organizations identify potential violations efficiently while maintaining proper audit records and reports.
